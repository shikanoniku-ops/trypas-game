## 4. GitHub Pages へのデプロイ

### 4.1 自動デプロイ（GitHub Actions）

`.github/workflows/deploy.yml` により、以下のブランチにプッシュすると自動デプロイされます：
- `main`
- `feature/v2-update`

### 4.2 ワークフロー設定

```yaml
name: Deploy to GitHub Pages

on:
  push:
    branches:
      - main
      - feature/v2-update

permissions:
  contents: read
  pages: write
  id-token: write

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: "20"
      - name: Clean install dependencies
        run: |
          rm -f package-lock.json
          npm install
      - name: Build
        run: npm run build
        env:
          NODE_ENV: production
      - uses: actions/upload-pages-artifact@v3
        with:
          path: ./dist

  deploy:
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    runs-on: ubuntu-latest
    needs: build
    steps:
      - uses: actions/deploy-pages@v4
```

### 4.3 GitHub Pages 環境設定

1. **Settings** → **Pages** を開く
2. **Source** で **「GitHub Actions」** を選択
3. **Settings** → **Environments** → **github-pages** を開く
4. **Deployment branches** を **「All branches」** に設定

## 5. Vite 設定（GitHub Pages対応）

`vite.config.js`:
```javascript
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'

export default defineConfig({
  plugins: [react()],
  base: process.env.NODE_ENV === 'production' ? '/trypas-game/' : '/',
})
```

### 重要: アセットパスの指定

GitHub Pages では `base` パスが `/trypas-game/` になるため、画像などの静的アセットは以下のように指定：

```jsx
// ❌ 間違い
<img src="/trypas-logo-new.png" />

// ✅ 正しい
<img src={`${import.meta.env.BASE_URL}trypas-logo-new.png`} />
```

## 6. トラブルシューティング

### 問題: ロゴ/画像が表示されない
**原因**: パスが `/` で始まっている  
**解決**: `import.meta.env.BASE_URL` を使用

### 問題: `@rollup/rollup-linux-x64-gnu` が見つからない
**原因**: Windows で生成した package-lock.json に Linux 用のオプショナル依存が含まれていない  
**解決**: ワークフローで `rm -f package-lock.json` を追加

### 問題: 「Branch is not allowed to deploy」エラー
**原因**: 環境保護ルールでブランチが制限されている  
**解決**: Settings → Environments → github-pages で「All branches」を選択

## 7. Vercel へのデプロイ（代替手段）

Vercel でのデプロイも可能です：

1. [vercel.com](https://vercel.com) にアクセス
2. GitHubリポジトリをインポート
3. ビルド設定:
   - **Framework**: Vite
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
   - **Node Version**: 20.x
4. 環境変数（オプション）: `NODE_ENV=production`
