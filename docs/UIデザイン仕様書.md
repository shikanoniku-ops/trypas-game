## 1. デザインコンセプト

### 1.1 テーマ: サイバーパンク
近未来的なサイバーパンク風デザインを採用。ダークテーマをベースに、ネオンカラーのアクセントを使用。

### 1.2 カラーパレット

| 用途 | カラー | HEX |
|------|--------|-----|
| **背景（メイン）** | ダークブルー | `#080810` |
| **背景（グラデ）** | ミッドナイト | `#0a0a1a` |
| **ネオンシアン** | アクセント1 | `#00FFFF` |
| **ネオンマゼンタ** | アクセント2 | `#FF00FF` |
| **ネオンパープル** | アクセント3 | `#9945FF` |
| **ネオングリーン** | 成功 | `#00FF88` |
| **ネオンイエロー** | 警告 | `#FFD700` |
| **テキスト** | ホワイト | `#FFFFFF` |
| **テキスト（サブ）** | グレー | `#94a3b8` |

### 1.3 コマの色

| コマ | 背景色 | ボーダー | 得点 |

## 2. タイトル画面

### 2.1 構成要素
- **背景**: CyberpunkBackground コンポーネント
  - ヘキサゴンパターン（SVG）
  - ニューラルライン（アニメーション）
  - フローティングオーブ（アニメーション）
  - グロウグラデーション
- **ロゴ**: `trypas-logo-new.png`（ネオン発光エフェクト付き）
- **サブタイトル**: "ABSTRACT STRATEGY GAME"
- **バージョンバッジ**: "PROTOTYPE | v0.3.3"

### 2.2 ボタン一覧
| ボタン | スタイル | 動作 |
|--------|----------|------|
| SOLO PLAY | プライマリ（白背景） | ソロモード開始 |
| TUTORIAL | セカンダリ（緑背景） | チュートリアル開始 |
| VS CPU | アウトライン | CPUモード選択へ |
| 2 PLAYERS | アウトライン | 2人対戦開始 |
| ルール説明 | プライマリ（青背景） | ルールモーダル表示 |
| 🔊/🔇 | アイコン | 音声ON/OFF |

### 2.3 難易度選択（VS CPU）
- EASY: 初級AI
- NORMAL: 中級AI
- HARD: 上級AI

## 4. ゲーム終了画面（GameOverModal）

### 4.1 デザイン
- **背景**: 半透明ダーク + ブラー
- **モーダル**: ネオンボーダー + テックコーナー
- **タイトル**: "GAME OVER"（グロー付き）
- **タイトル**: "GAME OVER"（グロー付き）
- **勝者表示**: "勝者: [YOU/CPU/P1/P2]"（ネオンバッジ）
- **スコアカード**: 両プレイヤーのスコア

### 4.2 ボタン
| ボタン | VS MODE | SOLO |
|--------|---------|------|
| 盤面を確認する | ❌ 非表示 | ✅ 表示 |
| 次のプレイ | ✅ 表示 | ✅ 表示 |
| 同じ盤でプレイ | ✅ 表示 | ✅ 表示 |
| リプレイを見る | ✅ 表示 | ✅ 表示 |
| タイトルへ戻る | ✅ 表示 | ✅ 表示 |
