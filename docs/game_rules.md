# TRYPAS ゲームルール（最新版）

**バージョン:** 2.1  
**最終更新:** 2026-02-03  

---

## 共通ルール

TRYPAS（トライパス）は、三角形状に配置されたコマを取り合い、スコアを競うボードゲームです。

### 盤面構成
- 15マスの三角形盤面
- 各色3個ずつ、計15個のコマがランダムに配置

### 基本的な動き
1. **コマの移動**: 任意のコマを選び、隣接するコマ（1〜3個）を飛び越えて空いているマスに着地
2. **コマの獲得**: 飛び越えられたコマの**最後の1個のみ**が取り除かれ、自分のスコアになる
3. **連続ジャンプ**: 一度に**最大3個**までのコマを飛び越えることができる（一直線上に限る）

### スコア
コマの色によって得点が異なります：

| 色 | 得点 |
|----|------|
| 🔴 **赤 (RED)** | 10点 |
| 🟡 **黄 (YELLOW)** | 20点 |
| 🟢 **緑 (GREEN)** | 30点 |
| 🔵 **青 (BLUE)** | 40点 |
| ⚪ **白 (WHITE)** | 50点 |

### 赤コマの統一ルール（全モード共通）
1. **初手の制限**: ゲーム開始時、**赤コマを最初に取り除くことはできません**
2. **最後に赤コマを取った場合**: **ペナルティ**が発生します（詳細は各モードを参照）

## ⚔️ VS MODE（対戦モード）

2人で対戦するモードです（VS CPU または 2 PLAYERS）。

### 勝敗判定
- **引き分けはありません** - 必ず勝負が決まります
- 相手を**手詰まり（動かせるコマがない状態）**にさせたプレイヤーの勝利
- つまり、**最後の1手を打ったプレイヤーの勝利**

### 赤コマの特殊効果 (TRYPAS!)
- 赤コマを獲得すると、**もう一度続けて自分のターン**になります（追加ターン）
- 画面に「**TRYPAS!**」エフェクトが表示されます

### 敗北条件
以下のいずれかで敗北となります：
1. 自分のターンで動かせるコマがなくなった場合（手詰まり）
2. **最後の1手で赤コマを取って終了した場合**（自爆ルール）

### スコア表示
- **敗者のスコアは0点**になります
- 勝者のスコアはそのまま保持されます

### 勝敗判定まとめ
| 終了時の状況 | 勝者 | 敗者 | 敗者スコア |
|---|---|---|---|
| 青・黄・緑・白を取って手詰まり | 手番プレイヤー | 相手プレイヤー | 0点 |
| **赤**を取って手詰まり | 相手プレイヤー | 手番プレイヤー | 0点 |

## 🎮 SOLO PLAY（ソロプレイ）

1人でハイスコアを目指すモードです。

### 独自のルール
1. **赤コマの扱い**:
   - ソロプレイでは赤コマを取っても**TRYPAS!エフェクトは発生しません**
   - 一人プレイでは追加ターンの意味がないためです
2. **盤面確認機能**:
   - ゲーム終了後、盤面を確認するボタンが表示されます

### ゲーム終了条件
- 盤面上でこれ以上コマを動かせなくなった時点でゲーム終了

### ペナルティ
- **最後の1手で赤コマを取って終了した場合**、スコアが**0点**になります
- それ以外の場合は、獲得した合計スコアが記録されます

### 目標スコア
- 全コマの合計得点は**450点**です
- 赤コマを最後に残すと取れないため、理論上の最高得点は**440点**です
- 赤コマを最後に残さないように戦略的にプレイしましょう

---

## 🎓 TUTORIAL（チュートリアル）

初心者向けのガイド付きモードです。

### 特徴
- ステップバイステップでルールを学べます
- 実際にコマを動かしながらプレイ方法を理解できます
- いつでもスキップ可能

## ゲームモード一覧

| モード | 説明 | TRYPAS! | 敗者0点 |
|--------|------|---------|---------|
| **SOLO PLAY** | 1人でハイスコアを目指す | ❌ 無効 | ❌ 該当なし |
| **VS CPU (EASY)** | CPU対戦（初級） | ✅ 有効 | ✅ 適用 |
| **VS CPU (NORMAL)** | CPU対戦（中級） | ✅ 有効 | ✅ 適用 |
| **VS CPU (HARD)** | CPU対戦（上級） | ✅ 有効 | ✅ 適用 |
| **2 PLAYERS** | ローカル2人対戦 | ✅ 有効 | ✅ 適用 |
| **TUTORIAL** | チュートリアル | ❌ 無効 | ❌ 該当なし |
