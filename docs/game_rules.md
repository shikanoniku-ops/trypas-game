# TRYPAS ゲームルール

## 共通ルール
TRYPAS（トライパス）は、三角形状に配置されたコマを取り合い、スコアを競うボードゲームです。

### 基本的な動き
1. **コマの移動**: 任意のコマを選び、隣接するコマを飛び越えて空いているマスに着地します。
2. **コマの獲得**: 飛び越えられたコマは盤面から取り除かれ、自分のスコアになります。
3. **スコア**: コマの色によって得点が異なります。
   - 🔴 **赤**: 10点
   - 🟡 **黄**: 20点
   - 🟢 **緑**: 30点
   - 🔵 **青**: 40点
   - ⚪ **白**: 50点
4. **連続ジャンプ**: 一度に最大3つまでのコマを飛び越えることができます（一直線上に限る）。

## ⚔️ VS MODE（対戦モード）
2人で対戦するモードです（VS CPU または 2 PLAYERS）。

### 独自のルール
1. **勝利条件**:
   - 相手を**手詰まり（動かせるコマがない状態）**にさせたプレイヤーの勝利です。
   - つまり、**最後の1手を打ったプレイヤーの勝利**となります。
2. **赤コマの特殊効果 (TRYPAS!)**:
   - **赤コマ**を獲得すると、**もう一度続けて自分のターン**になります（追加ターン）。
   - これをうまく利用することで、連続して得点を稼いだり、相手の手を封じたりすることができます。
3. **敗北条件**:
   - 自分のターンで動かせるコマがなくなった場合（手詰まり）。
   - **最後の1手で赤コマを取って終了した場合**、そのプレイヤーは**即座に敗北**となります（勝利条件の例外）。

### 勝敗判定まとめ
| 終了時の状況 | 勝者 | 敗者 |
|---|---|---|
| 最後の1手で**青・黄・緑・白**を取って手詰まり | 手番プレイヤー | 相手プレイヤー |
| 最後の1手で**赤**を取って手詰まり | 相手プレイヤー | 手番プレイヤー（自爆） |

## 🎮 SOLO PLAY（ソロプレイ）
1人でハイスコアを目指すモードです。

### 独自のルール
1. **初手の制限**:
   - ゲーム開始時、**赤コマ（10点）** を最初に取り除くことはできません。
2. **ゲーム終了条件**:
   - 盤面上でこれ以上コマを動かせなくなった時点でゲーム終了です。
3. **ゲームオーバー判定（敗北条件）**:
   - **最後の１手で赤コマを取って終了した場合**、ペナルティとして**スコアが0点**になります。
   - それ以外の場合は、獲得した合計スコアが記録されます。
